### Phase 6: API Integration ✅
- ✅ **Create Article**: `POST /api/news/create/route.ts`
  - Accepts rich HTML content
  - Validates content length (max 1MB)
  - Sanitizes before storage
  - Generates unique slug
  - Admin-only access
  - Returns article ID and slug

- ✅ **Update Article**: `PUT/PATCH /api/news/[id]/update/route.ts`
  - Full update (PUT) and partial update (PATCH)
  - Updates title, content, excerpt, category, tags
  - Sets lastEditedAt timestamp
  - Sanitizes content server-side
  - Admin-only access

- ✅ **Publish Article**: `POST/DELETE /api/news/[id]/publish/route.ts`
  - POST to publish (sets publishedAt)
  - DELETE to archive (soft delete)
  - Sets draft/published flags appropriately

- ✅ **Get Article**: `GET /api/news/[id]/route.ts`
  - Returns all article fields
  - Public access for published articles
  - Auth required for draft articles
  - Includes comment count
