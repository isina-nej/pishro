# News Markdown Rendering Spec

## Modified Requirements

### Requirement: Magazine-Style Markdown Rendering

سیستم باید متون خام Markdown را به بلوک‌های استایل‌دهی شده و حرفه‌ای تبدیل کند که تجربه خواندن مجله‌ای را تداعی کند.

#### Scenario: Rendering Inline Markdown Images

- GIVEN یک متن خبری با فرمت Markdown حاوی ساختار `![توضیحات عکس](image-url.jpg)` یا `![توضیحات](image-url.jpg "subtitle")`
- WHEN کاربر صفحه خبر را لود می‌کند
- THEN تصویر باید داخل بلوکی مجزا و وسط‌چین رندر شود
- AND تصویر باید دارای گوشه‌های گرد و سایه ملایم باشد
- AND `alt` یا `title` تصویر باید به صورت زیرنویس `figcaption` در زیر تصویر نمایش داده شود
- AND تصویر باید به صورت lazy load (کاهنده CLS و بهتر برای عملکرد) بارگذاری شود

### Functional Requirements

- FR-001: محتوا باید در یک کانتینر مرکزی با حداکثر عرض خوانایی (`max-w-3xl`) قرار بگیرد.
- FR-002: تایپوگرافی پاراگراف‌ها باید حداقل `line-height: 1.85` داشته باشد.
- FR-003: تصاویر Markdown باید `next/image` یا یک پیاده‌سازی بهینه‌شده مشابه را برای بارگذاری ارائه دهند.
- FR-004: نقل‌قول‌ها باید با حاشیه برجسته، پس‌زمینه متمایز و فونت ایتالیک استایل داده شوند.
- FR-005: متن‌های طولانی باید بدون اسکرول افقی در موبایل نمایش داده شوند.
