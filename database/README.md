# راهنمای پایگاه داده Pishro

## نظرۀ کلی

این پروژه از یک فایل SQL مرکزی برای مدیریت تمام جداول پایگاه داده و داده‌های اولیه استفاده می‌کند.

## ساختار فایل‌ها

```
database/
└── schema-and-seed.sql    # فایل مرکزی شامل جداول و داده‌های اولیه
```

## فایل اصلی: schema-and-seed.sql

### بخش‌های موجود:

#### 1. **جداول کاربران و احراز هویت**
- `User` - اطلاعات کاربران اصلی
- `TempUser` - کاربران موقتی در مرحله OTP
- `Otp` - کدهای OTP برای تأیید شماره تلفن

#### 2. **جداول محتوای اصلی**
- `Category` - دسته‌بندی‌های دوره
- `Course` - دوره‌های آموزشی
- `Lesson` - درس‌های هر دوره
- `Comment` - نظرات کاربران روی دوره‌ها
- `Enrollment` - ثبت‌نام کاربران در دوره‌ها

#### 3. **جداول تست و کوئیز**
- `Quiz` - کوئیزهای دوره
- `QuizAttempt` - تلاش‌های کاربران برای کوئیز

#### 4. **جداول سفارش و پرداخت**
- `Order` - سفارش‌های خریداری
- `OrderItem` - آیتم‌های هر سفارش
- `Transaction` - تراکنش‌های پرداخت

#### 5. **جداول صفحات استاتیک**
- `AboutPage` - صفحه درباره ما
- `BusinessConsulting` - صفحه مشاوره تجاری
- `HomeLanding` - بخش‌های صفحه اصلی
- `HomeSlide` - اسلاید‌های صفحه اصلی
- `HomeMiniSlider` - اسلاید‌های کوچک
- `MobileScrollerStep` - مراحل اسکرول موبایل

#### 6. **جداول اخبار و نظرات**
- `News` - مقالات اخبار
- `NewsComment` - نظرات روی اخبار

#### 7. **جداول برنامه‌های سرمایه‌گذاری**
- `InvestmentPlan` - برنامه‌های سرمایه‌گذاری
- `InvestmentPlans` - صفحه برنامه‌های سرمایه‌گذاری
- `InvestmentTag` - تگ‌های سرمایه‌گذاری
- `UserInvestmentPortfolio` - پورتفولیو سرمایه‌گذاری کاربران

#### 8. **جداول تکمیلی**
- `FAQ` - سوالات متداول
- `Tag` - برچسب‌ها
- `Image` - تصاویر کاربران
- `Certificate` - گواهی‌نامه‌ها
- `TeamMember` - اعضای تیم
- `ResumeItem` - آیتم‌های رزومه

### داده‌های اولیه (Seeds):

#### دسته‌بندی‌ها:
1. **بورس** (stock)
2. **ارزهای دیجیتال** (cryptocurrency)
3. **NFT** (nft)
4. **ایردراپ** (airdrop)
5. **متاورس** (metaverse)

#### دوره‌های نمونه:
1. آموزش کامل بورس برای مبتدیان - 299,000 تومان
2. ارزهای دیجیتال و بلاک‌چین پیشرفته - 399,000 تومان
3. تحلیل تکنیکال بورس - 349,000 تومان
4. NFT و توکن‌های دیجیتال - 279,000 تومان
5. ایردراپ و کسب توکن رایگان - 199,000 تومان

## چگونگی استفاده

### اجرا کردن فایل SQL:

#### روش 1: استفاده از MySQL CLI
```bash
mysql -h localhost -u root -p pishro < database/schema-and-seed.sql
```

#### روش 2: از داخل MySQL
```sql
source /path/to/database/schema-and-seed.sql;
```

#### روش 3: استفاده از Docker Compose
```bash
docker-compose exec mysql mysql -h localhost -u root -p pishro < database/schema-and-seed.sql
```

## بهینه‌سازی‌های انجام شده

✅ **یک فایل مرکزی** - تمام جداول و داده‌های اولیه در یک فایل
✅ **استفاده از IF NOT EXISTS** - جلوگیری از خطا هنگام اجرای مجدد
✅ **استفاده از INSERT IGNORE** - جلوگیری از تکراری داده‌های اولیه
✅ **کامنت‌های فارسی** - سهولت درک ساختار
✅ **ترتیب منطقی جداول** - جداول پایه اول، سپس جداول وابسته
✅ **Foreign Keys صحیح** - ارتباط دقیق بین جداول
✅ **Charset مناسب** - utf8mb4_unicode_ci برای پشتیبانی از فارسی

## نکات مهم

⚠️ این فایل شامل **تمام جداول و داده‌های اولیه** است
⚠️ **داده‌های اولیه اختیاری** هستند و می‌توان بدون اجرای بخش seeds فقط جداول را ایجاد کرد
⚠️ **Prisma Schema** باید با این ساختار **همطور** بوده و در صورت تغیار باید به‌روزرسانی شود
