## عناوین و سرتیترها

از `#` برای ایجاد عناوین استفاده کنید. هر `#` یک سطح بالاتر است.

```markdown
# عنوان 1 (بزرگ‌ترین)
## عنوان 2
### عنوان 3
#### عنوان 4
##### عنوان 5
###### عنوان 6 (کوچک‌ترین)
```

**نتیجه مورد انتظار:**
- هر عنوان با فونت‌های مختلف و فاصله‌گذاری حرفه‌ای نمایش داده می‌شود
- عناوین اصلی (`h1`) نسبت به سایرین بزرگ‌تر و پررنگ‌تر هستند

## متن و فرمت‌کننده‌های متنی

### متن عادی
```markdown
این یک متن عادی است که خودکار به صورت پاراگراف نمایش داده می‌شود.
```

### متن پررنگ (Bold)
```markdown
این **متن پررنگ** است.
```

### متن شیب‌دار (Italic)
```markdown
این *متن شیب‌دار* است.
```

### متن پررنگ و شیب‌دار
```markdown
این ***متن پررنگ و شیب‌دار*** است.
```

### خط‌خورده
```markdown
این ~~متن خط‌خورده~~ است.
```

### کد درون‌خطی (Inline Code)
```markdown
استفاده از `محتوای کد` درون متن.
```

**نکته**: تمام این فرمت‌ها خودکار بدون کلیک بروی دکمه‌های فرمت رندر می‌شوند.

## لیست‌ها

### لیست بدون ترتیب (Bullet List)
```markdown
- مورد اول
- مورد دوم
  - زیر‌مورد
- مورد سوم
```

### لیست باترتیب (Numbered List)
```markdown
1. مورد اول
2. مورد دوم
   1. زیر‌مورد
3. مورد سوم
```

**نکته**: خط‌فاصل و فاصله‌گذاری خودکار اعمال می‌شود.

---

## نقل‌قول‌ها

```markdown
> این یک نقل‌قول است که با استایل خاص نمایش داده می‌شود.
>
> می‌تواند چندین پاراگراف داشته باشد.
```

**نتیجه مورد انتظار:**
- نقل‌قول با رنگ آبی و پس‌زمینه تک‌رنگ نمایش داده می‌شود
- مرزی در سمت راست (برای نوشتار راست‌به‌چپ) اضافه می‌شود

## تصاویر

### درج تصویر ساده
```markdown
![توضیح تصویر](https://example.com/image.jpg)
```

### تصویر با عنوان
```markdown
![توضیح تصویر](https://example.com/image.jpg "عنوان تصویر")
```

**نکات مهم:**
- تصاویر خودکار در وسط صفحه وسط‌چین می‌شوند
- لبه‌های گرد و سایه حرفه‌ای اضافه می‌شود
- عنوان زیر تصویر با فونت کوچک نمایش داده می‌شود
- تصاویر واکنش‌پذیر هستند و بر اساس اندازه صفحه تطبیق می‌یابند

## کد و دستورات

### کد درون‌خطی
```markdown
استفاده از `console.log()` برای چاپ.
```

### بلوک کد (Code Block)

#### جاوا‌اسکریپت
```javascript
function hello() {
  console.log("سلام");
}
```

#### Python
```python
def hello():
    print("سلام")
```

#### HTML
```html
<div class="hello">سلام</div>
```

**نکات:**
- نام زبان برنامه‌نویسی خودکار نمایش داده می‌شود
- شماره خطوط خودکار اضافه می‌شود
- رنگ‌بندی نحوی (Syntax Highlighting) خودکار اعمال می‌شود
- بلوک کد با رنگ تاریک و فونت مونو نمایش داده می‌شود

## جدول‌ها

```markdown
| سرتیتر 1 | سرتیتر 2 | سرتیتر 3 |
|---------|---------|---------|
| سلول ۱۱  | سلول ۱۲  | سلول ۱۳  |
| سلول ۲۱  | سلول ۲۲  | سلول ۲۳  |
```

**نکات:**
- جدول‌ها خودکار استایل مدرن دریافت می‌کنند
- سرتیترها پررنگ و با پس‌زمینه رنگی نمایش داده می‌شوند
- جدول‌های بزرگ در موبایل اسکرول‌پذیر هستند

## نکات و بهترین‌روش‌ها

### ✅ بهترین‌روش‌ها

1. **عناوین واضح**: از عنوان اول برای عنوان مقاله استفاده کنید
   ```markdown
   # عنوان اصلی مقاله
   
   ## بخش اول
   محتوای بخش...
   ```

2. **تصاویر معنادار**: همیشه توضیح معنادار برای تصاویر بنویسید
   ```markdown
   ![نمودار افزایش فروش سال ۱۴۰۴](image.jpg)
   ```

3. **فاصله‌گذاری مناسب**: پاراگراف‌ها را با خط خالی جدا کنید
   ```markdown
   پاراگراف اول

   پاراگراف دوم
   ```

4. **کوتاهی متن**: پاراگراف‌ها را کوتاه نگه دارید (3-4 جمله)

5. **استفاده از لیست‌ها**: برای نقاط متعدد از لیست‌ها استفاده کنید

### ❌ اشتباه‌های رایج

1. **بدون عنوان اصلی**: مقاله بدون عنوان اول درست نیست
2. **تصاویر بدون توضیح**: همیشه توضیح تصویر را بنویسید
3. **فاصله‌گذاری ضعیف**: متن‌ها را بدون فاصله نویسید
4. **استفاده زیادی از فرمت**: متن را بیش‌از‌حد پررنگ یا شیب‌دار نکنید
5. **کدهای بدون نام زبان**: همیشه نام زبان برنامه‌نویسی را مشخص کنید
